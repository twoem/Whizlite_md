# Whiz-Lite-Assets

This repository serves as the protected command kernel and asset storage for the Whiz-Lite-MD ecosystem. It contains the main processing engine, command plugins, scrapers, and UI templates.

## Structure

-   `kernel/`: Core processing and command routing.
-   `plugins/`: Over 120 standalone command files.
-   `scrapers/`: Data scraping utilities.
-   `ui_templates/`: Visual components for messages.
-   `assets/`: Static assets like banners, fonts, and stickers.
